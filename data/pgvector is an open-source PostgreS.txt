pgvector is an open-source PostgreSQL extension that enables high-performance vector similarity search and storage of embeddings directly within a relational database, eliminating the need for separate vector database infrastructure.  It adds a native vector data type to PostgreSQL, allowing developers to store numerical representations of text, images, or other data alongside traditional relational data using standard SQL. 

Key capabilities include support for multiple distance metrics (L2, Cosine similarity, and Inner product) and efficient indexing via HNSW and IVFFlat algorithms, which enable fast approximate nearest neighbor searches.  This makes it particularly suitable for powering semantic search, retrieval-augmented generation (RAG), recommendation systems, and anomaly detection without introducing architectural complexity or vendor lock-in.

While pgvector offers low operational complexity and leverages PostgreSQL’s ACID compliance and hybrid search capabilities, it has practical scaling limits; performance may degrade with very high vector counts (10M+) without optimization, and HNSW indexes are memory-intensive. For most applications under this scale, it provides a robust, unified solution, though teams requiring massive horizontal scaling or billions of vectors may need external tooling or specialized vector databases.
